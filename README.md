
# UNI Lost & Found

A university lost-and-found web application developed as an academic team project at Umm Al-Qura University.

## Project Overview

UNI Lost & Found helps students report and search for lost or found items through a simple web interface.

The application also includes an administrative dashboard for managing reports and viewing item statistics.

## Key Features

- Submit lost and found item reports
- Upload item images
- Search for reported items
- Admin login and report management
- Dashboard with item statistics by category

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
